# UI-UX-Experiment3
## Aim:
To design a responsive and user-friendly Swiggy mobile food delivery application using modern UI/UX principles.
## Algorithm:

1. Create a login screen with logo, welcome text, and login options.

2. Design a homepage with search bar, categories, and restaurant listings.

3. Add filter options like Near Me and Fast Delivery.

4. Create restaurant cards with image, rating, delivery time, and price.

5. Apply consistent colors, spacing, and navigation elements.

6. Improve usability using responsive mobile layout and interaction design.
